# Loan Default Risk Prediction: 307,511 Credit Applications Analyzed with 3 Machine Learning Models

Summary: 
This project analyzed 307,511 Home Credit loan application records to predict the risk of default using Logistic Regression, Random Forest, and XGBoost. The results showed an AUC-ROC of 0.63–0.66, with Logistic Regression emerging as the best model. This analysis yielded recommendations for initial risk scoring, customer segmentation, and improvements in handling missing data to enhance prediction quality.
